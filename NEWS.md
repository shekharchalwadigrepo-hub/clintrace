# clintrace 0.1.0

Initial release.

* Core lineage recording and querying (`new_trace`, `add_lineage`, `query_lineage`).
* Helpers for derivation + lineage capture (`derive_with_trace`, `wrap_derive`).
* Validation (`validate_trace`).
* Reporting (`trace_report`).
* Define-XML friendly metadata export.
* Example data, vignettes, and GitHub Actions CI.
